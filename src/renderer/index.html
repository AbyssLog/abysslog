Data & Recovery

AbyssLog writes a verified full database backup on each clean exit and retains the latest seven automatic backups. Full backups preserve characters, run details, settings, and encrypted credentials. Restoring creates a safety copy of the current database and restarts AbyssLog. After reinstalling the operating system, you may need to reconnect EVE characters and re-enter the Janice API key.

Export run history from the History tab. CSV imports support quoted multiline cargo fields and skip runs already recorded for the same character and start time.

Diagnostics

AbyssLog keeps a short-lived local event log to help diagnose startup, database, ESI, Janice, and interface failures. It does not contain tokens, API keys, authorization URLs, character details, inventories, or stack traces, and it is never sent automatically.
